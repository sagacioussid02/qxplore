The context window

A language model can only “see” a limited number of tokens at once — that limit is its context window. Watch what happens when a conversation runs longer than the window: it fills up, then starts sliding, and the oldest tokens fall out the back.

SPEED
01

The budget is fixed

The window holds a set number of tokens and never grows. Everything the model knows about your conversation has to fit inside it — your messages, its replies, and any instructions all share the same budget.

02

Newest in, oldest out

Once the window is full, it slides forward: each new token pushes the oldest one out. In the animation, the fact stated at the very start — the secret word — is pushed out long before the question about it arrives.

03

Outside the window = forgotten

A token that falls out isn’t stored somewhere else — as far as the model is concerned, it was never said. That’s why very long chats can “forget” things mentioned near the beginning.

Shown small on purpose: this window holds only a handful of tokens so you can watch it slide. Real context windows hold from about 8,000 to over 1,000,000 tokens — but the rule is identical. One simplification: here each token is a whole word; real tokenizers split text into sub-word pieces, so a word like unforgettable might be three tokens.
