1 / 4  Pick a function f — constant or balanced?

You are handed a black box for a function f that takes one bit and returns one bit, with a promise: f is either constant — the same answer for every input — or balanced — half the inputs give 0 and half give 1. Your job: tell which kind it is, with as few questions to the box as possible. The worked example is NOT x: f(0) = 1, f(1) = 0, balanced.

Classically, one input bit needs 2 questions to be sure: you have to see both f(0) and f(1), because a single answer — say f(0) = 1 — could come from a constant function (always 1) or a balanced one (NOT x). The gap grows fast with more input bits — see step 4.

2 / 4  Walk the circuit, one gate at a time

The Deutsch–Jozsa circuit for one input bit uses a second qubit as a helper. Start in |0⟩|1⟩, put a Hadamard on both qubits, ask the oracle once (phase kickback stamps the answer onto the first qubit as a sign), then a final Hadamard on the first qubit turns that phase into a probability you can measure. The helper qubit stays |−⟩ the whole way through — it is only there to do the kicking back.

3 / 4  Run the algorithm — is the answer certain?

The whole circuit uses the oracle exactly once. Run it and watch the measurement: a constant function always gives 0, a balanced one always gives 1. Run it 100 times — the tally should not budge. That certainty is the point: the final Hadamard turned a phase difference into a probability difference of 100% vs 0%.

4 / 4  Scale it up: more input bits, same one query

With n input bits the circuit is the same idea, wider: n input qubits plus the helper, Hadamards everywhere, one oracle call, Hadamards on the inputs, then measure. A constant function always reads out all zeros; a balanced one never does. Classically the worst case is 2n−1 + 1 questions — you could see 2n−1 identical answers in a row and still not know. With n = 3 input bits there are 8 possible inputs. A balanced function has four 0s and four 1s, so you could ask four times, see four 0s, and still not know — the fifth answer settles it. The quantum circuit asks once and reads all zeros for constant, anything else for balanced.

Worked example: f(x) = NOT x, so f(0) = 1 and f(1) = 0 — balanced. After the first Hadamards the state is |+⟩|−⟩. The oracle stamps a −1 onto the |0⟩ term (f(0) = 1) and leaves the |1⟩ term alone (f(1) = 0), giving (−|0⟩ + |1⟩) / √2 = −|−⟩. The final Hadamard turns |−⟩ into |1⟩, so you measure 1 — balanced, with certainty. A constant f would have left both signs the same, so the final Hadamard would give back |0⟩. Classically you would have needed both f(0) and f(1) — two questions — to reach the same conclusion.
