1 / 2  Every single-qubit state is one point on a sphere

North pole = |0⟩, south pole = |1⟩, equator = even 50/50 mixes. θ (down from the north pole) sets the probabilities; φ (around the equator) is the phase — invisible to a plain measurement, but a real part of the state.

|ψ⟩ = 0.71|0⟩ + 0.71|1⟩

θ = 90° from |0⟩ · φ = 0° around the equator

θ — down from the north pole |0⟩ 90°
φ — around the equator (the phase) 0°

2 / 2  Read the state in Dirac notation

A bra ⟨ψ| is a ket flipped around. A bracket ⟨φ|ψ⟩ measures how much two states agree: 1 = identical, 0 = completely different. A measurement probability is a bracket, squared: P(0) = |⟨0|ψ⟩|².

Measure 0 — P(0) = cos²(θ/2)50%
Measure 1 — P(1) = sin²(θ/2)50%

⟨0|ψ⟩ = 0.71  ·  ⟨1|ψ⟩ = 0.71
|⟨+|ψ⟩|² = 1.00 — this state is |+⟩

Worked example: this starting point is |+⟩ — θ = 90°, φ = 0°, so |ψ⟩ = (1/√2)|0⟩ + (1/√2)|1⟩. |−⟩ sits exactly opposite (φ = 180°) and also measures 50/50, yet ⟨+|−⟩ = 0 — as different as two qubit states can be. The phase is invisible to a plain measurement, but gates can feel it.
