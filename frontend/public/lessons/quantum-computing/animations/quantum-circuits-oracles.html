1 / 4  Pick a classical function f

An oracle is a box that stands for a classical function f: it computes f without telling you how. The algorithm that calls it never looks inside — it just counts how many times it has to ask. Here f takes one bit and returns one bit, so there are only four possible functions. The worked example is NOT x: f(0) = 1, f(1) = 0.

2 / 4  The bit oracle: the answer as a bit

The bit oracle writes the answer into a spare qubit: Uf |x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩. It flips the spare qubit exactly when f(x) = 1, and leaves it alone when f(x) = 0. Pick an input and a spare-qubit value, then apply the oracle.

3 / 4  Phase kickback: the answer as a sign

Prepare the spare qubit in the state |−⟩ = (|0⟩ − |1⟩) / √2 instead. That state is special: flipping it changes nothing but a minus sign, X|−⟩ = −|−⟩. So when the oracle flips the spare qubit — which it does exactly when f(x) = 1 — the minus sign has nowhere to go but back onto the input: Uf |x⟩|−⟩ = (−1)f(x) |x⟩|−⟩. The spare qubit comes out exactly as it went in; the input carries the answer as a phase. Pick an input and apply the oracle.

4 / 4  Try it on a superposition — and measure

Now feed the phase oracle a superposition instead of a single input: |+⟩ = (|0⟩ + |1⟩) / √2. Each term picks up its own sign, (−1)f(x), so the oracle can turn |+⟩ into a different state — but a phase is invisible to a direct measurement. Apply it, then measure 100 fresh copies and watch the tally.

The phase oracle sorts functions into two camps: constant functions leave |+⟩ alone, and balanced functions turn it into |−⟩. That sorting is exactly what the next lesson exploits.

Worked example: f(x) = NOT x, so f(0) = 1 and f(1) = 0. The bit oracle flips the spare qubit when the input is 0 and leaves it when the input is 1: |0⟩|0⟩ becomes |0⟩|1⟩, while |1⟩|0⟩ stays |1⟩|0⟩. With the spare qubit in |−⟩, the phase oracle gives −|0⟩ for input 0 and +|1⟩ for input 1 — so on |+⟩ it returns (−|0⟩ + |1⟩) / √2, which is |−⟩ up to an overall minus sign that carries no information. Constant functions do nothing at all to |+⟩: if f is always 0 nothing flips, and if f is always 1 both terms flip, which is again just an overall sign. A phase is invisible to a direct measurement — |+⟩ and |−⟩ both measure 50/50 — but the next gate can feel it, and that is the whole point.
